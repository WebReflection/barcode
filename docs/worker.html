Worker API, three ways

One session, one worker, two explicit entries. These buttons prove the page entry, the @webreflection/barcode/worker entry spawned by the page, and that same worker entry statically imported at the top of your own module Worker.

1 · Page entry

import barcode from '@webreflection/barcode/main' gives the session factory. There is no bare package entry.

2 · Explicit /worker entry

Spawn worker.js yourself, then hand it to barcode({ worker }). The same worker renders and scans.

3 · Worker entry, imported at the top

A module Worker that imports @webreflection/barcode/worker statically at the top; its default is the bootstrap promise, resolved by the page's first message (the MessagePort). The page binds it with barcode({ worker }).
